对比介绍

这一类像一桌 AI 火锅：ollama 负责把模型端上桌，LocalAI 负责把各种菜都做成 OpenAI 兼容口味，Milvus 像专门记人脸和记忆点的仓库，Fabric、Crush、Reasonix 则偏向把模型变成可用的工作助手。

如果你只是想本地跑模型，别一上来就搭一个豪华厨房；ollama 足够像电饭煲一样简单。若要给团队提供统一接口，new-api、CLIProxyAPI 更像前台收银，把不同模型供应商藏在后厨。

不同场景下的最优选择

  • 本地个人玩模型：优先 ollama，少折腾，启动快。
  • 需要 OpenAI 兼容 API：优先 LocalAI 或 new-api。
  • 做 RAG / 语义搜索：Milvus 是正经仓库管理员。
  • 想让 AI 参与编码：Crush、DeepSeek-Reasonix、beads 更贴近开发工作流。
  • 做 AI 安全或红队自动化：pentagi 更像拿着放大镜的机器人侦探。

对比介绍

Web 框架这桌很像选交通工具：Gin 是可靠小钢炮，Echo 简洁利落，Fiber 像从 Node/Express 搬家的同学专车，Beego/Iris 功能更全但行李也更多。

微服务框架里 go-zero、Kratos、Go kit 更像套餐饭，配好了日志、RPC、配置、治理；chi、mux、fasthttp 更像单件工具，轻便但需要自己搭配。

不同场景下的最优选择

  • 普通 API 服务：Gin 通常最稳，资料多，团队沟通成本低。
  • 喜欢 Express 风格：Fiber 上手最快。
  • 轻量路由：chi 比较优雅，适合不想把厨房装修成商场的人。
  • 企业微服务：go-zero 或 Kratos 更省集成时间。
  • 极限 HTTP 性能：fasthttp 可以上，但别忘了它和标准库生态不是完全一条街。

静态站点与前端构建

项目 Stars 简介
gohugoio/hugo 89K 极速静态网站生成器
evanw/esbuild 40K 极快的 JS/CSS 打包与压缩工具

对比介绍

Hugo 和 esbuild 都追求一个字：快。Hugo 负责把内容变成网站，esbuild 负责把前端资源打包到飞起。

Hugo 像高铁写博客，适合文档站、博客和官网；esbuild 像前端流水线的涡轮增压器，适合 JS/CSS 构建。

不同场景下的最优选择

  • 搭博客/文档站：选 Hugo。
  • 前端构建和压缩：选 esbuild。
  • 想少配点东西：Hugo 更像开箱即用的电动车。

Docker/Moby/containerd/Podman 负责容器本身，Rancher、k9s、lazydocker 负责让人类不至于在命令行迷路，Harbor 管镜像仓库，Argo CD 管部署节奏。

不同场景下的最优选择

  • 生产级集群：Kubernetes 是标准答案。
  • 边缘/小机器/实验环境：k3s 很香。
  • 本地学习 K8s：minikube 或 k3s，别一开始就搬整座云。
  • 管理集群：k9s 适合终端党，Rancher 适合平台化管理。
  • GitOps 部署：Argo CD 是常见优选。
  • 镜像分析瘦身：dive 看层，slim 减肥，像给镜像办健身卡。

v2ray/Xray/sing-box/hysteria 更偏通用代理与复杂网络场景，功能强但配置像乐高，拼得好是城堡，拼不好是脚底板灾难。

  • K8s / 云原生入口：Traefik 更自然。
  • 私有组网：Tailscale 简单，headscale 适合自托管控制面。
  • 复杂代理：sing-box 或 Xray-core，配置前建议先泡杯茶。

对比介绍

数据库这类像仓库选址：TiDB/CockroachDB 管大规模分布式交易，MinIO/SeaweedFS 管对象和文件，etcd 管关键配置，Milvus 这类向量库则是给 AI 找相似记忆的。

不同场景下的最优选择

  • MySQL 兼容分布式数据库：TiDB。
  • 强一致分布式 SQL：CockroachDB。
  • 对象存储：MinIO。
  • K8s 配置协调：etcd。
  • 图数据：Dgraph。
  • 喜欢 ORM：GORM；喜欢 SQL 可控：sqlc 或 sqlx。

对比介绍

这类项目负责让服务之间别靠吼。gRPC 是高速公路，grpc-gateway 是收费站翻译官，NATS/NSQ 是消息快递，Temporal 像不怕断电的流程管家。

不同场景下的最优选择

  • 高性能 RPC：grpc-go。
  • 需要 REST 兼容：grpc-gateway。
  • 轻量消息：NATS。
  • 实时分布式消息：NSQ。
  • 长流程/重试/补偿：Temporal。
  • 多运行时能力抽象：Dapr。

  • 多网盘聚合：Alist 或 OpenList。
  • 简单 Web 文件管理：Filebrowser。
  • 一次性安全传文件：croc。
